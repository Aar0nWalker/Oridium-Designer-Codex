# Oridium Designer Codex

Это набор, который даёт тебе AI-помощника прямо внутри твоих программ: **Figma, Blender, Photoshop, Illustrator, After Effects, InDesign, Premiere Pro**.

Ты пишешь помощнику обычными словами — «сделай обложку», «анимируй логотип», «свёрстай этот макет» — а он сам двигает слои, ставит текст и собирает результат в открытой программе.

Настройка занимает минут 20 и делается один раз. Просто иди по шагам.

---

## Что понадобится

- Компьютер на **macOS** (для Windows — короткая заметка в конце).
- **Подписка ChatGPT** (Plus, Pro или Team) — на ней работает помощник.
- Сами программы, с которыми работаешь (Figma, Photoshop и т.д.) — нужны только те, которыми пользуешься ты.

---

## Шаг 1. Установи VS Code

Это бесплатная программа-редактор, внутри которой живёт помощник. Думай о ней как об офисе для него.

1. Скачай отсюда: **https://code.visualstudio.com/** (большая синяя кнопка).
2. Открой скачанный файл и перетащи значок VS Code в папку «Программы».

## Шаг 2. Установи Node.js

Служебная программа, нужна установщику. Ставится как любое приложение.

1. Скачай отсюда: **https://nodejs.org/** (зелёная кнопка **LTS**).
2. Открой скачанный файл и жми «Далее» до конца.

## Шаг 3. Скачай этот набор

1. Открой **Терминал**: нажми `Cmd + Пробел`, напиши «Терминал», нажми Enter. Откроется окно, куда можно вставлять команды.
2. Скопируй эти три строки целиком, вставь в Терминал и нажми Enter:

```bash
git clone https://github.com/Aar0nWalker/Oridium-Designer-Codex
cd Oridium-Designer-Codex
bash setup/install.sh
```

3. Подожди пару минут — установщик всё сделает сам и в конце напишет «Готово».

> Если мак предложит установить «Command Line Tools» — соглашайся, дождись установки и вставь те же три строки ещё раз.

## Шаг 4. Включи помощника в VS Code

1. Открой VS Code.
2. Слева на панели нажми значок из четырёх кубиков (Extensions).
3. В поиске напиши **Codex**, выбери «Codex — OpenAI's coding agent» и нажми **Install**.
4. Нажми **Sign in** и войди в свой аккаунт ChatGPT.

## Шаг 5. Открой папку набора

1. В VS Code: меню **File → Open Folder…**
2. Выбери папку **Oridium-Designer-Codex** (она в твоей домашней папке — там, куда её положил Шаг 3).
3. Если спросит «Do you trust the authors?» — нажми **Yes, I trust**.

Всё. Помощник готов. Осталось подключить твои программы.

## Шаг 6. Подключи свои программы (по одному разу)

Подключай только те, которыми пользуешься. Самый простой способ — **попроси самого помощника**: открой чат Codex в VS Code и напиши:

> Помоги мне подключить Photoshop по инструкции docs/SETUP.md

Он проведёт тебя по шагам. Если хочешь сам — вся инструкция в файле [docs/SETUP.md](docs/SETUP.md). Коротко, что там:

- **Figma** — в приложении Figma включается один переключатель (Dev Mode → MCP server).
- **Blender** — устанавливается маленький аддон и нажимается кнопка Connect.
- **Photoshop / Illustrator / After Effects / InDesign / Premiere** — устанавливается панель-плагин, в ней нажимается Connect.

## Как работать каждый день

1. Открой VS Code → папку Oridium-Designer-Codex → чат Codex.
2. Открой программу, в которой работаешь (и нажми Connect в её панели, если это Adobe или Blender).
3. Если работаешь с программами Adobe — сначала напиши помощнику: **«запусти прокси Adobe»** (или сам открой в VS Code меню Terminal → New Terminal и вставь `bash scripts/start-adobe-proxy.sh`). Это мостик между помощником и Adobe, его окно должно оставаться открытым.
4. Пиши задачи обычными словами:

> «Сделай в Photoshop обложку 1920×1080 с крупным заголовком SALE и тёмным фоном»
> «Возьми выделенный фрейм в Figma и собери такой же экран»
> «Сделай в Blender простую 3D-сцену: горы на закате, низкополигональный стиль»
> «Анимируй появление логотипа в After Effects: плавное увеличение за 2 секунды»
> «Оцени мой макет и скажи, что улучшить»

## Сделай помощника «своим»

- Заполни файл [brand/BRAND.md](brand/BRAND.md) — впиши свои фирменные цвета, шрифты и стиль. После этого все работы будут сразу в твоём стиле.
- Помощник запоминает твои правки: поправишь его пару раз — дальше будет делать как ты любишь.

---

## Что-то не работает?

- Первым делом — **спроси самого помощника**: «у меня не работает Photoshop, разберись». Он знает, что проверять.
- Помощник не видит программу Adobe → проверь три вещи: запущен прокси (шаг 3 выше), программа открыта, в её панели нажат Connect.
- Помощник не видит Figma → Figma должна быть открыта как **приложение на компьютере** (не в браузере), и включён переключатель MCP.
- Совсем ничего не работает → закрой VS Code полностью и открой заново.

## Windows

Всё то же самое, только на Шаге 3 вместо Терминала открой **PowerShell** (меню Пуск → напиши «PowerShell») и вставь:

```powershell
git clone https://github.com/Aar0nWalker/Oridium-Designer-Codex
cd Oridium-Designer-Codex
powershell -ExecutionPolicy Bypass -File setup/install.ps1
```

Если напишет, что нет `git` — установи его отсюда: https://git-scm.com/downloads и повтори.
