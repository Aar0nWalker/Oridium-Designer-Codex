# Oridium Designer Codex

Набор, который даёт тебе AI-помощника прямо внутри твоих программ: **Figma, Blender, Photoshop, Illustrator, After Effects, InDesign, Premiere Pro**.

Ты пишешь ему обычными словами: «сделай обложку», «анимируй логотип», «свёрстай этот макет». Он сам двигает слои, ставит текст и собирает результат в открытой программе.

Настройка займёт минут двадцать, и делается она один раз. Просто иди по шагам.

---

## Что понадобится

- Компьютер на **macOS** (для Windows есть короткая заметка в конце).
- **Подписка ChatGPT** (Plus, Pro или Team). На ней работает помощник.
- Программы, в которых ты работаешь. Нужны только твои: пользуешься Figma и Photoshop, значит хватит их двоих.

---

## Шаг 1. Установи VS Code

Бесплатный редактор, внутри которого живёт помощник. Считай, что это его офис.

1. Скачай: **https://code.visualstudio.com/** (большая синяя кнопка).
2. Открой скачанный файл и перетащи значок VS Code в папку «Программы».

## Шаг 2. Установи Node.js

Служебная штука, без неё не отработает установщик. Ставится как обычное приложение.

1. Скачай: **https://nodejs.org/** (зелёная кнопка **LTS**).
2. Открой файл и жми «Далее» до конца.

## Шаг 3. Скачай набор

1. Открой **Терминал**: нажми `Cmd + Пробел`, набери «Терминал», Enter. Появится окно для команд.
2. Скопируй три строки разом, вставь в Терминал, нажми Enter:

```bash
git clone https://github.com/Aar0nWalker/Oridium-Designer-Codex
cd Oridium-Designer-Codex
bash setup/install.sh
```

3. Пару минут подожди. Установщик всё сделает сам и в конце напишет «Готово».

> Мак может предложить установить «Command Line Tools». Соглашайся, дождись конца установки и вставь те же три строки ещё раз.

## Шаг 4. Включи помощника в VS Code

1. Открой VS Code.
2. На левой панели нажми значок из четырёх кубиков (Extensions).
3. В поиске набери **Codex**, выбери «Codex, OpenAI's coding agent», нажми **Install**.
4. Нажми **Sign in** и войди в свой аккаунт ChatGPT.

## Шаг 5. Открой папку набора

1. В VS Code: меню **File → Open Folder…**
2. Выбери папку **Oridium-Designer-Codex**. Она лежит в твоей домашней папке, туда её положил Шаг 3.
3. На вопрос «Do you trust the authors?» отвечай **Yes, I trust**.

Всё, помощник на месте. Осталось познакомить его с твоими программами.

## Шаг 6. Подключи свои программы (по одному разу)

Подключай только те, что нужны. Самый простой путь: **попроси самого помощника**. Открой чат Codex и напиши:

> Помоги мне подключить Photoshop по инструкции docs/SETUP.md

Он проведёт по шагам. Любишь разбираться сам? Вся инструкция лежит в [docs/SETUP.md](docs/SETUP.md). Если коротко:

- **Figma**: в приложении включается один переключатель (Dev Mode → MCP server).
- **Blender**: ставится маленький аддон, жмёшь Connect.
- **Photoshop / Illustrator / After Effects / InDesign / Premiere**: ставится панель-плагин, в ней жмёшь Connect.

## Как работать каждый день

1. Открой VS Code, папку Oridium-Designer-Codex, чат Codex.
2. Открой рабочую программу. Для Adobe и Blender нажми Connect в её панели.
3. Работаешь с Adobe? Сначала скажи помощнику: **«запусти прокси Adobe»**. Это мостик между ним и Adobe, окно с прокси должно жить, пока ты работаешь. Хочешь руками: в VS Code меню Terminal → New Terminal, вставь `bash scripts/start-adobe-proxy.sh`.
4. Дальше просто пиши задачи:

> «Сделай в Photoshop обложку 1920×1080 с крупным заголовком SALE и тёмным фоном»
> «Возьми выделенный фрейм в Figma и собери такой же экран»
> «Сделай в Blender 3D-сцену: горы на закате, низкополигональный стиль»
> «Анимируй появление логотипа в After Effects: плавное увеличение за 2 секунды»
> «Оцени мой макет и скажи, что улучшить»

## Сделай помощника своим

- Заполни [brand/BRAND.md](brand/BRAND.md): фирменные цвета, шрифты, стиль. После этого каждая работа сразу выходит в твоём стиле.
- Помощник запоминает правки. Поправишь его пару раз, и дальше он делает так, как любишь ты.

---

## Что-то не работает?

- Первым делом спроси самого помощника: «у меня не работает Photoshop, разберись». Он знает, что проверять.
- Не видит программу Adobe? Проверь три вещи: прокси запущен, программа открыта, в её панели нажат Connect.
- Не видит Figma? Figma должна быть открыта как **приложение на компьютере**, не в браузере, и с включённым переключателем MCP.
- Совсем всё сломалось? Закрой VS Code целиком и открой заново. Чаще всего этого хватает.

## Windows

Всё то же самое, только на Шаге 3 вместо Терминала открой **PowerShell** (Пуск → набери «PowerShell») и вставь:

```powershell
git clone https://github.com/Aar0nWalker/Oridium-Designer-Codex
cd Oridium-Designer-Codex
powershell -ExecutionPolicy Bypass -File setup/install.ps1
```

Напишет, что нет `git`? Установи его отсюда: https://git-scm.com/downloads и повтори.
