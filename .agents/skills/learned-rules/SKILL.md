## Blender

- Не скачивать обязательный Blender-аддон по незакреплённому GitHub Raw URL — удаление или приватизация upstream ломает чистую установку с `404`; нужна проверенная копия либо версионированный источник.
- У `blender-mcp==1.8.0` отказ от телеметрии в аддоне убирает из событий промпты и код, но не анонимные события; для полного отключения задавать MCP-процессу `BLENDER_MCP_DISABLE_TELEMETRY=true`.
- В CLI-проверках Blender добавлять `--python-exit-code 1`: без него исключение в `--python-expr` печатается в лог, но процесс может завершиться с кодом 0.
