# Figma (Dev Mode MCP)

## Перед работой

- Сервер живёт в **десктопном** приложении Figma: Dev Mode → Enable MCP server (`127.0.0.1:3845`).
- Инструменты читают **текущее выделение** пользователя. Нет выделения — попроси выделить фрейм/компонент и скажи зачем.
- Если инструменты недоступны — Figma закрыта или MCP-сервер выключен; назови это пользователю, не гадай.

## Рабочий процесс

1. Получи контекст выделения (структура, стили, переменные) и скриншот фрейма — сверяй результат с картинкой, а не только с деревом слоёв.
2. При генерации кода по макету: сначала вытяни дизайн-токены (цвета, типографика, отступы) и используй их, а не «на глаз» подобранные значения.
3. Большой макет разбирай по фреймам: один фрейм → один проход, иначе контекст ответа сервера обрезается.
4. Ассеты (иконки, картинки) экспортируй через инструменты сервера, а не перерисовывай.

## Грабли

- Figma в браузере не даёт MCP — только десктоп-приложение.
- Dev Mode доступен не на всех тарифах; если тумблера нет — у пользователя нет Dev Mode seat.
- Сервер отдаёт только то, что выделено, — «весь файл целиком» он не отдаст.
