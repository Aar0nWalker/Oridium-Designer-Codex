# Самообучение

После каждой ситуации из списка ниже допиши урок в `.agents/skills/learned-rules/SKILL.md` (раздел нужной программы):

- пользователь поправил твой результат («не так», «переделай», «я же говорил») — зафиксируй, КАК правильно;
- инструмент/скрипт не сработал с первого раза, а обход нашёлся — зафиксируй обход;
- вскрылась особенность программы, которой нет в её скилле (версия, формат, единицы, лимит).

## Формат урока

Одна строка: `- Правило — почему/симптом.` Пример:

```
- Текст в AE ставить только после выбора шрифта из списка доступных — иначе молча подставляется Arial.
```

## Правила ведения

1. Перед записью проверь, нет ли уже такого урока — обновляй существующий, а не плоди дубли.
2. Записывай только ПОВТОРЯЕМОЕ (правило на будущее), а не детали разовой задачи.
3. Устаревший или опровергнутый урок удаляй сразу.
4. Предпочтения конкретного пользователя (любимые шрифты, стиль, форматы) — тоже уроки: раздел «Предпочтения пользователя».
5. Если урок относится к одной программе и он важный — можно продублировать его в раздел «Грабли» скилла этой программы.
