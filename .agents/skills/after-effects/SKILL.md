# After Effects (adb-mcp, ExtendScript)

## Перед работой

Цепочка: **прокси запущен** → **After Effects открыт** → **CEP-панель подключена** (Window → Extensions → adb-mcp → Connect).
Панели нет — не установлено CEP-расширение или PlayerDebugMode (docs/SETUP.md).

## Рабочий процесс

Управление через ExtendScript (JavaScript ES3):

1. Один скрипт — одно действие: создать композицию, добавить слой, поставить ключи. После каждого — читающий скрипт-проверка (что создалось, какие параметры).
2. Всё изменяющее оборачивай в `app.beginUndoGroup("...")` / `app.endUndoGroup()` — пользователь сможет откатить твой шаг одним Ctrl+Z.
3. Композицию задавай явно: размер, fps, длительность — из задачи (сторис 1080×1920/30fps, реклама 1920×1080/25fps…), не полагайся на дефолт.
4. Анимация: сначала ключевые кадры на transform-свойствах, easing — через `setTemporalEaseAtKey` или выражения. Выражения держи короткими и проверяй, что не выдали ошибку (красный баннер у свойства).
5. Время в секундах (float), а не в кадрах — переводи из кадров сам.

## Грабли

- ES3: `var` и функции, никаких современных конструкций.
- Индексы слоёв и свойств — с **1**, не с 0; слой №1 — верхний.
- Ошибочное выражение молча отключается — после установки выражения проверь `expressionError`.
- Рендер очереди долгий и грузит машину — запускай только по явной просьбе.
