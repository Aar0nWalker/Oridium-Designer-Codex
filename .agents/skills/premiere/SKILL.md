# Premiere Pro (adb-mcp)

## Перед работой

Цепочка: **прокси запущен** → **Premiere открыт (свежая версия/Beta)** → **UXP-плагин загружен и Connect нажат**.
adb-mcp требует свежий Premiere (Beta-ветка) — если инструменты не работают на стабильной версии, скажи об этом пользователю.

## Рабочий процесс

1. Узнай структуру проекта (bins, секвенции) перед изменениями.
2. Секвенцию создавай под целевой формат: вертикаль 1080×1920 для соцсетей, 1920×1080 для YouTube; fps — от исходников.
3. Импортируй медиа явными путями, раскладывай по bins с понятными именами.
4. Монтаж шагами: положил клип → проверил позицию/длительность на таймлайне → следующий. Не выстраивай весь таймлайн одной пачкой команд.
5. Аудио: следи, чтобы клипы не перекрывали друг друга случайно; музыку — на отдельную дорожку.

## Грабли

- Пути к медиа — абсолютные; файл, которого нет на диске, создаст offline-клип без ошибки.
- Операции с таймлайном необратимы через API так же чисто, как руками, — перед крупной перестройкой попроси пользователя сохранить проект.
- Экспорт/рендер — долгий и по явной просьбе.
