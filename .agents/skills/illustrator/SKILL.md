# Illustrator (adb-mcp, ExtendScript)

## Перед работой

Цепочка: **прокси запущен** → **Illustrator открыт** → **CEP-панель подключена** (Window → Extensions → adb-mcp → Connect).
Панели нет в меню — не установлено CEP-расширение или не включён PlayerDebugMode (docs/SETUP.md).

## Рабочий процесс

Управление идёт через выполнение ExtendScript (JavaScript ES3!):

1. Пиши маленькие самодостаточные скрипты: один скрипт — одно действие (создать артборд, нарисовать фигуру, добавить текст). После каждого — проверь результат следующим читающим скриптом.
2. ES3: никаких `let`/`const`/стрелок/`JSON` — только `var`, функции, ручная сборка строк.
3. Координаты Illustrator: ось Y растёт **вверх**, точка отсчёта — левый нижний угол артборда. Проверь позицию первого объекта, прежде чем расставлять остальные.
4. Цвета — через объекты `RGBColor`/`CMYKColor`; для печати уточни цветовую модель документа.
5. Группируй логически связанные объекты и именуй слои — файл потом разбирает человек.

## Грабли

- Ошибка ExtendScript часто молчалива: скрипт «выполнился», а объекта нет. Всегда возвращай из скрипта результат/подтверждение и читай его.
- Сложные контуры строй из примитивов и `pathPoints` постепенно — гигантский путь одним скриптом почти всегда кривой.
- Не трогай объекты вне своей задачи: у дизайнера в файле может быть рабочая область рядом.
