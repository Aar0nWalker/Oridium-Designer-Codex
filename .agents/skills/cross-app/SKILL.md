# Сквозной процесс между программами

## Какая программа для чего

| Этап | Инструмент |
|---|---|
| UI/веб-макеты, прототипы, дизайн-системы | Figma |
| Вектор: лого, иконки, иллюстрации | Illustrator |
| Растр: ретушь, коллажи, обложки | Photoshop |
| Анимация графики, титры, моушн | After Effects |
| Многостраничная вёрстка, печать, PDF | InDesign |
| Видеомонтаж из готовых кусков | Premiere Pro |
| 3D-объекты, сцены, рендеры | Blender |

Задачу веди в «родной» программе этапа, а не тяни всё в одну.

## Передача материалов

- **Вектор → AE/Photoshop**: сохраняй `.ai` (AE импортирует слоями) или экспортируй SVG/PDF; в растр конверти только на финальном шаге.
- **Figma → код/растр**: токены и структуру читай через Figma MCP; картинки — экспортом из Figma (2x для растра), не скриншотом.
- **Blender → Photoshop/AE**: рендер в PNG с альфа-каналом (RGBA), для анимации — секвенция PNG или ProRes.
- **AE → Premiere**: рендер в ProRes/DNxHR, не H.264 — монтажный кодек переживает повторное сжатие.
- **Печать (InDesign)**: изображения 300 dpi, CMYK; экран — 72–144 dpi, sRGB. Конвертируй профиль осознанно, один раз, в конце.
- Один проект — одна папка: `assets/` (исходники), `work/` (рабочие файлы программ), `export/` (результаты). Имена файлов: `проект_сущность_v01`.

## Правила

1. Составь маршрут заранее («лого в Illustrator → анимация в AE → подложить в Premiere») и назови его пользователю до начала.
2. На каждом переходе проверяй: размер, прозрачность, цветовой профиль, частоту кадров — потери живут на стыках.
3. Исходники не перезаписывай промежуточными экспортами; экспорт — всегда новый файл в `export/`.
4. Перед сквозной задачей убедись, что подключены ВСЕ нужные программы (прокси Adobe — один на всех, но плагин подключается в каждом приложении отдельно).
