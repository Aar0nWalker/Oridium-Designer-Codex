# Blender (blender-mcp)

## Перед работой

- В Blender должен быть включён аддон BlenderMCP и нажата **Connect** в сайдбаре (вкладка BlenderMCP, клавиша `N`).
- Не отвечает — попроси пользователя открыть Blender и нажать Connect; не долби повторами.

## Рабочий процесс

1. Сначала `get_scene_info` — пойми, что уже есть в сцене, прежде чем добавлять.
2. Строй сцену шагами: объект → трансформация → материал → свет → камера. После каждого блока — скриншот вьюпорта и сверка.
3. Python-код в Blender выполняй маленькими порциями через инструмент выполнения кода; каждая порция — самодостаточна (import bpy внутри).
4. Материалы и HDRI бери из Poly Haven (если включён в панели аддона) — быстрее и качественнее ручной сборки.
5. Имена объектов давай осмысленные (`mountain_low_poly`, не `Cube.003`).

## Грабли

- Длинный скрипт, упавший в середине, оставляет сцену в полусобранном состоянии — потом убери мусор.
- Не удаляй и не перезаписывай объекты пользователя без явной просьбы; новое — в новую коллекцию.
- Тяжёлые операции (рендер, физика, много ассетов) вешают Blender на минуты — предупреждай пользователя заранее.
