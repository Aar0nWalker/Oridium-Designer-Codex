# Ревью дизайна

## Как проводить

1. Получи актуальную картинку: скриншот из Figma/Blender, превью документа из Adobe. Ревью по дереву слоёв без картинки не делать.
2. Пройди по чек-листу и дай **конкретные правки с числами** («заголовок 64→96px, отступ до подзаголовка 8→24px»), а не общие слова («сделать выразительнее»).
3. Разведи категории: «сломано» (мешает пользоваться) → «слабо» (ухудшает восприятие) → «вкусовое» (можно оставить). Начинай со сломанного.
4. Если есть `brand/BRAND.md` — сверь с ним (цвета, шрифты, тон).
5. По согласию пользователя примени правки сам — по одной, с проверкой после каждой.

## Чек-лист

- **Иерархия**: главное считывается первым? один визуальный акцент, а не три?
- **Типографика**: не больше 2 гарнитур; размеры по шкале, а не случайные; межстрочный 1.2–1.5; строки не длиннее ~70 знаков.
- **Выравнивание и отступы**: единая сетка; одинаковые сущности — одинаковые отступы; ничего не «почти по краю».
- **Цвет и контраст**: текст читается на фоне (для UI — контраст не ниже 4.5:1); акцентный цвет один; цвета из палитры, не соседние оттенки.
- **Читаемость в контексте**: как выглядит в реальном размере (превью телефона для сторис, миниатюра для обложки)?
- **Края и вылеты**: ничего важного не прижато к краю; для печати — вылеты 3–5 мм и текст внутри безопасной зоны.
